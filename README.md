# Retro Pac-Man Arcade 🕹️

Game arcade retro klasik Pac-Man yang dibuat menggunakan HTML5 Canvas, Vanilla CSS, dan JavaScript murni dengan efek suara 8-bit sintetis (Web Audio API).

## 🚀 Fitur
- **Visual Retro & Neon Glow**: Tampilan arcade dengan animasi canvas yang halus (60 FPS).
- **AI 4 Hantu Klasik**: Blinky, Pinky, Inky, dan Clyde dengan kepribadian dan pola serang masing-masing.
- **Power Pellets**: Makan pelet besar untuk membalikkan keadaan dan memakan hantu demi skor ekstra (+200, +400, +800, +1600).
- **Audio 8-Bit Tanpa Aset Eksternal**: Sintesis audio dinamis menggunakan Web Audio API.
- **Dukungan Multi-Kontrol**: Keyboard (Panah & WASD) serta tombol D-Pad virtual untuk perangkat sentuh / mobile.
- **Penyimpanan High Score**: Skor tertinggi tersimpan otomatis di browser menggunakan `localStorage`.

## 🎮 Cara Menjalankan
Buka file `index.html` langsung di browser, atau jalankan server lokal:
```bash
node server.js
```
Lalu akses `http://localhost:3000` di browser Anda.
